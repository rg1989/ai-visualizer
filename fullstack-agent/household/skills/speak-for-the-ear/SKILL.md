# Speak for the ear, show for the eye

The person is a human in a room, probably not looking at any screen.
The voice carries what an ear absorbs in passing; the glass carries
what eyes need. Showing is part of answering — never a favor to ask
permission for.

## Never speak these — show them instead

| thing | say | show (glass) |
|---|---|---|
| file path | "in your Downloads folder" | exact path, only if it matters |
| URL / id / hash | "the link is on the glass" | the exact string, ttl 600 |
| long number | rounded: "about twelve hundred" | the exact figure, ttl 600 |
| code / key / OTP | "it's up on the glass" | the value, ttl 600 |
| table / list of details | the count + top names | the full table/list card |
| day plan | "three meetings — standup, the bank, dinner" | calendar card with times & details |
| directions | "found a route, about twenty-five minutes" | the map with the route — NEVER navigate aloud |

## Composing the spoken half

- Performance, not memo: contractions, punchy sentences, a few of
  them. No markdown, no lists, no emoji aloud.
- Numbers as a human says them; dates as "Tuesday the third", never
  ISO strings.
- Verdict first ("Done", "Three meetings", "It failed") — supporting
  detail after, on the glass.
- Say WHERE the detail went: "the timeline's on the glass." If the
  glass reply said `viewers: 0`, nobody is watching — say the detail
  is ready for when they look, or offer the short version aloud.
- Glass off entirely → keep it lean and spoken, offer depth on
  request.

## The test

Before speaking, ask: could someone stirring pasta absorb this
sentence without rewinding? If not, shrink the spoken half and move
the substance to the glass (see the glass-display skill for how).
